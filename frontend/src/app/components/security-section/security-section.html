Soberanía y Privacidad

Tus finanzas no son un producto publicitario.

La mayoría de las aplicaciones financieras analizan tus hábitos para vender créditos, seguros o colocar anuncios intrusivos. Luma fue concebida bajo un paradigma radicalmente opuesto: tú eres el único dueño de tu información.

Row Level Security (RLS) en Postgres

Tus transacciones y cuentas están aisladas a nivel de base de datos en Supabase. Ninguna petición puede consultar datos que no pertenezcan estrictamente a tu token de sesión.

Autenticación OAuth con Google

Inicio de sesión sin contraseñas locales intermediarias. El flujo oficial de Google Sign-In garantiza la protección biométrica de tu dispositivo.

Código Abierto y Auditable

Transparencia total. Puedes inspeccionar las migraciones SQL, la lógica de Flutter y el backend directamente en el repositorio público de GitHub.

Compromiso de Privacidad

Nunca venderemos tus datos, nunca insertaremos anuncios y nunca compartiremos información con centrales de riesgo.
